# 管理台

默认地址 `http://127.0.0.1:17810`，或公网面的 `/admin/`（见[部署](deploy.md#安全)）。

## 页面

| 页面 | 用途 |
|---|---|
| Bot 管理 | 添加（扫码或填凭据）、编辑、启停 bot；查看每个群的状态并启用/禁用；「分组」里建分组、设默认分组（新 bot 都进默认分组） |
| 黑白名单 | 按 bot 查看、增删启用的群与被禁用的用户 |
| 聊天 | 以 bot 身份在群里/私聊收发消息、撤回、禁言 |
| 记录 → 消息 | 所有收发记录，可按内容 / ID 搜索；详情里能看图片、视频，下载文件 |
| 记录 → ID | 每个 bot 下用户与群的 ID 对照 |
| 统计 | 消息量走势、活跃会话与时段、发送配额 |
| 设置 → 选项 | 全局选项、更新 |
| 设置 → 插件 | 插件开关与配置 |
| 设置 → 后端 | 后端预设：一组 OneBot 反向 WebSocket 地址，新 bot 按默认预设接入（直连 OneBot 或经 BotShepherd）。已有的 bot 在「编辑」里「应用预设」：直连模式填入端点、保存生效；BotShepherd 模式直接改它那条连接的下游 |
| 设置 → 存储 | 数据库、媒体、日志占用与清理 |
| 设置 → 账号 | 管理台账号 |
| 帮助 | 内置指令与常见问题 |

## 角色与权限

首次登录会提示把初始密码改掉；任何账号都能点右上角自己的用户名改密码。

账号有三种角色，在「设置 → 账号」里分配：

| 能做什么 | 只读 | 高级 | 管理员 |
|---|:-:|:-:|:-:|
| 查看 bot、名单、ID、统计、帮助、选项、插件 | ✅ | ✅ | ✅ |
| 聊天：收发消息、撤回、禁言、上传 | | ✅ | ✅ |
| 查看消息记录与详情 | | ✅ | ✅ |
| 添加、编辑、重载 bot，扫码接入，给 bot 配后端 | | ✅ | ✅ |
| 增删黑白名单 | | ✅ | ✅ |
| 查看后端配置与存储占用 | | ✅ | ✅ |
| 删除 bot、查看 AppSecret | | | ✅ |
| 新建 bot 分组 | | ✅ | ✅ |
| 分组改名、删除、设默认 | | | ✅ |
| 修改选项、插件、后端预设、BotShepherd 密码 | | | ✅ |
| 清理存储、更新 | | | ✅ |
| 管理账号 | | | ✅ |

简单说：**高级**适合日常运营（管 bot 和群、在聊天页收发），碰不到全局配置、账号和危险操作；**管理员**什么都能做。
